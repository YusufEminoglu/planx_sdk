PlanX SDK Reference Manual

PlanX SDK is a scientific-grade Python library delivering high-performance spatial statistics, network accessibility, multi-criteria decision analysis (MCDA), and urban climate resilience engines. Completely headless and decoupled from GUI dependencies, it enables automated geospatial computation pipelines across Jupyter notebooks, serverless cloud workers, and microservices.

12+ Scientific Modules
100% Headless & Non-GUI
< 5ms Vectorized KDTree & CSR
480+ Automated Unit Tests

Headless Architecture vs QGIS Plugin

While the PlanX QGIS Plugin offers rich desktop interactive UI/UX for urban planners within QGIS, the PlanX SDK abstracts the core computational algorithms into a pure, stateless Python package.

PlanX QGIS Plugin (GUI)
  • Interactive canvas drawing, layer styling, and Qt dialogs
  • Tied to desktop QGIS application process lifecycle
  • Requires manual clicks and GUI-based scenario testing
  • Difficult to integrate into CI/CD pipelines or Docker workers
PlanX SDK (Headless Core)
  • Pure Python & NumPy: Zero QGIS GUI requirement
  • Cloud & Microservice Ready: FastAPI, Flask, AWS Lambda, Docker
  • Jupyter & Data Science Native: Direct integration with pandas/geopandas
  • Deterministic & Vectorized: Fast matrix routines and unit-testable

1. Spatial Network & Accessibility (`planx.spatial`)

The planx.spatial module provides high-speed shortest path computations on CSR graphs, topological centrality measures (Brandes betweenness, closeness, eigenvector, criticality), gravity-based accessibility models (Hansen Index), and Enhanced Two-Step Floating Catchment Area (E2SFCA) methods with spatial Gini equity evaluation.

ACCESSIBILITY & SPATIAL EQUITY

Enhanced Two-Step Floating Catchment Area (E2SFCA) & Hansen Gravity

The Enhanced 2-Step Floating Catchment Area (E2SFCA) calculates spatial accessibility $A_i$ of population demand point $i$ to service supply $j$ accounting for continuous distance friction:

Mathematical Formulation
$$\text{Step 1 (Provider to Population Ratio): } R_j = \frac{S_j}{\sum_{k \in \{d_{kj} \le d_0\}} D_k \cdot f(d_{kj})}$$ $$\text{Step 2 (Accessibility Score): } A_i = \sum_{j \in \{d_{ij} \le d_0\}} R_j \cdot f(d_{ij})$$ $$\text{Exponential Decay Function: } f(d) = \exp(-\beta \cdot d)$$
Function Core Parameters Mathematical Operation Returns
enhanced_2sfca(...) d_matrix, supply, demand, cutoff, decay_method Continuous floating catchment with decay weights np.ndarray ($N$ scores)
gravity_accessibility(...) matrix, weights, decay_method, beta, cutoff Hansen Potential Accessibility Index np.ndarray (Potential scores)
spatial_equity_gini(...) values, weights Population-weighted Gini Inequality Coefficient float ($G \in [0, 1]$)
service_area_coverage(...) indptr, adj, weights, facilities, thresholds CSR Dijkstra multi-threshold isochrone coverage dict[float, dict]
PYTHON USAGE 
import numpy as np
from planx.spatial import enhanced_2sfca, gravity_accessibility, spatial_equity_gini

# Distance matrix: 3 neighborhood origins to 2 hospitals (meters)
distances = np.array([
    [350.0, 1200.0],
    [800.0, 450.0],
    [1500.0, 2000.0]
])

hospital_beds = np.array([120.0, 250.0])
neighborhood_pop = np.array([1200.0, 3400.0, 1800.0])

# Calculate E2SFCA spatial accessibility (1500m catchment threshold)
e2sfca_scores = enhanced_2sfca(
    d_matrix=distances,
    supply=hospital_beds,
    demand=neighborhood_pop,
    cutoff=1500.0,
    decay_method="exponential",
    beta=0.0015
)
print("E2SFCA Scores:", e2sfca_scores)

# Assess equity of distribution via Population-Weighted Gini
gini = spatial_equity_gini(e2sfca_scores, neighborhood_pop)
print(f"Spatial Gini Inequality Index: {gini:.4f}")

2. Spatial Statistics & Autocorrelation (`planx.geostats`)

The planx.geostats module implements point & grid spatial interpolation (IDW via KDTree), spatial weight matrix generation ($k$-NN and distance-band), and exploratory spatial data analysis (ESDA) statistics: Global/Local Moran's I, Getis-Ord $G_i^*$, Local Geary's $C$, and Geographically Weighted Regression (GWR).

SPATIAL AUTOCORRELATION & HOTSPOT DETECTION

Getis-Ord $G_i^*$ and Anselin Local Moran's I

Getis-Ord $G_i^*$ Standardized Z-Score
$$G_i^* = \frac{\sum_{j=1}^n w_{ij} x_j - \bar{X} \sum_{j=1}^n w_{ij}}{S \sqrt{\frac{n \sum_{j=1}^n w_{ij}^2 - (\sum_{j=1}^n w_{ij})^2}{n - 1}}}, \quad \text{where } S = \sqrt{\frac{\sum x_j^2}{n} - (\bar{X})^2}$$
PYTHON USAGE 
import numpy as np
from planx.geostats import (
    create_knn_weights,
    calculate_getis_ord_gi,
    calculate_local_moran,
    idw_to_grid
)

# Coordinates and observed environmental values (e.g. PM2.5 levels)
coords = np.array([[10.0, 10.0], [12.0, 10.5], [11.0, 12.0], [50.0, 50.0]])
values = np.array([45.2, 48.0, 43.1, 12.5])
ids = [1, 2, 3, 4]

# Construct k-NN spatial weights
neighbors, weights = create_knn_weights(coords, ids, k=2)

# Compute Getis-Ord Gi* Hotspot Z-scores & P-values
gi_z, gi_p = calculate_getis_ord_gi(values, neighbors, weights, ids)
print("Hotspot Z-Scores:", gi_z)

# Interpolate to continuous 2D raster grid via KDTree IDW
grid, x_coords, y_coords = idw_to_grid(
    coords, values, bbox=(0.0, 0.0, 60.0, 60.0), cell_size=2.0, power=2.0
)
print(f"Interpolated Grid Shape: {grid.shape}")

3. Decision Analysis & Facility Optimization (`planx.suitability`)

The planx.suitability engine powers Multi-Criteria Decision Analysis (MCDA), Analytic Hierarchy Process (AHP), Entropy and CRITIC objective weighting, plus discrete combinatorial facility siting: Maximal Covering Location Problem (MCLP), $p$-Median, and Location Set Covering Problem (LSCP).

OPTIMIZATION & LOCATION ALLOCATION

MCLP and AHP Weighting with Consistency Index

Analytic Hierarchy Process (Saaty, 1980)
$$\mathbf{A} \mathbf{w} = \lambda_{\max} \mathbf{w}, \quad CI = \frac{\lambda_{\max} - n}{n - 1}, \quad CR = \frac{CI}{RI_n} < 0.10$$
PYTHON USAGE 
import numpy as np
from planx.suitability import ahp_weights, greedy_mclp, capacitated_location_allocation

# 1. Analytic Hierarchy Process (Pairwise Matrix)
ahp_matrix = np.array([
    [1.0, 3.0, 5.0],
    [0.333, 1.0, 2.0],
    [0.2, 0.5, 1.0]
])
weights, cr = ahp_weights(ahp_matrix)
print(f"AHP Weights: {weights}, Consistency Ratio: {cr:.4f} (Valid: {cr < 0.1})")

# 2. Greedy MCLP: Select K=2 emergency shelters to maximize population coverage within 500m
candidates = np.array([[100.0, 100.0], [500.0, 500.0], [900.0, 900.0]])
demands = np.array([[120.0, 130.0], [480.0, 520.0], [890.0, 910.0], [200.0, 300.0]])
pop = np.array([250.0, 600.0, 450.0, 180.0])

selected, step_pop, cum_pop = greedy_mclp(candidates, demands, pop, max_distance=500.0, k=2)
print("Optimal Shelter Siting Indices:", selected)
print(f"Total Covered Population: {cum_pop[-1]} / {pop.sum()} ({(cum_pop[-1]/pop.sum())*100:.1f}%)")

4. Urban Climate Resilience & Multi-Hazard (`planx.resilience`)

The planx.resilience module implements predictive disaster risk modeling, Monte Carlo seismic damage and debris expansion, DEM-based pluvial flood routing, SCS-CN peak runoff hydrographs, coastal bathtub inundation, wildfire spread front encroachment, Social Vulnerability Index (SVI), and post-disaster infrastructure network cascading disruption.

DISASTER SIMULATION & MULTI-HAZARD COMPOSITE

Seismic Debris Spread, Inundation & SVI Prioritization

Seismic Structural Collapse & Outward Debris Spread
$$P(\text{collapse} \mid M_w, \text{age}, \text{floors}) = \sigma(\alpha \cdot M_w + \beta \cdot \text{age} + \gamma \cdot \text{floors} + \epsilon)$$ $$R_{\text{debris}} = \sqrt{\frac{A_{\text{footprint}}}{\pi}} + k_d \cdot (N_{\text{floors}} \cdot h_{\text{floor}})$$
PYTHON USAGE 
import numpy as np
from planx.resilience import (
    simulate_seismic_debris,
    pluvial_flood_susceptibility,
    multi_hazard_composite,
    equity_adjusted_priority
)

# 1. Stochastic Seismic Monte Carlo Simulation (Mw 7.4 Scenario)
areas = np.array([150.0, 300.0, 80.0, 450.0])   # Footprint areas (m²)
floors = np.array([5.0, 9.0, 2.0, 12.0])        # Story counts
years = np.array([1988, 1975, 2018, 1994])      # Construction year

probs, collapsed, debris_radii, debris_vols = simulate_seismic_debris(
    building_areas=areas,
    building_floors=floors,
    building_years=years,
    magnitude=7.4,
    seed=42
)
print("Collapse Status (0: Safe, 1: Collapsed):", collapsed)
print("Debris Radii (m):", debris_radii)

# 2. Multi-Hazard Composite Synthesis with Social Vulnerability Amplifier
hazards = {
    "seismic": probs * 100.0,
    "flood": np.array([30.0, 80.0, 10.0, 65.0])
}
svi_index = np.array([85.0, 90.0, 20.0, 60.0])  # Social Vulnerability (0-100)

comp_scores, classes, dominant, diversity, drivers = multi_hazard_composite(hazards)
equity_scores, raw, factors, eq_classes = equity_adjusted_priority(
    comp_scores, svi_index, equity_weight=0.6
)
print("Equity-Adjusted Priority Scores for Intervention:", equity_scores)

planx.mobility

Traffic Assignment & BPR Link Performance

Implements Bureau of Public Roads (BPR) travel impedance functions and Frank-Wolfe convex optimization algorithm for user-equilibrium traffic assignment and Furness bi-proportional matrix balancing.

BPR Impedance Function
$$t_a(v_a) = t_a^0 \left[ 1 + \alpha \left( \frac{v_a}{C_a} \right)^\beta \right]$$
PYTHON 
from planx.mobility import bpr_link_performance_function, furness_matrix_balancing
import numpy as np

flows = np.array([1200.0, 1800.0])
capacities = np.array([1500.0, 1500.0])
free_time = np.array([3.0, 3.0])

travel_times = bpr_link_performance_function(flows, capacities, free_time, alpha=0.15, beta=4.0)
print("Congested Link Travel Times (min):", travel_times)
